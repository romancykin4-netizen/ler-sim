Как смотреть презентацию

На каждом экране три маленьких действия:

  1. Получаем вход. Смотрим, какие данные уже есть и кто их передал.
  2. Выполняем действие. Движение на схеме показывает смысл операции; рядом — настоящий код.
  3. Передаём результат. Фиксируем, что изменилось и зачем это нужно.

«Дальше» и «Назад» переключают именно действия. Ползунок и список переходят между экранами; главы слева — между большими этапами. «Автопоказ» выполняет действия с выбранным темпом.

Это учебная анимация по исходникам, не запись выполнения отладчика. Промежуточные траектории условные. Фактическое начало, конец и метрики запуска на 8 блоках выделены в последней главе.

Файл работает без интернета. Настоящая программа здесь не запускается: презентация объясняет её реализацию. Код проекта не изменяется.
